One original line of fortune-cookie wisdom for make.fun's "Fortune Cookie
Wisdom for Developers" bounty: a single line of at most 120 characters,
judged two at a time by a house judge playing a tired senior engineer.
`main.py` (pure Python stdlib, deterministic, no network) writes the line
to `/output/entry.txt`:

> Your legacy code is not a mess; it is a letter from a developer who loved this product before you did.

102 characters, one line. See `CANDIDATES.md` for the 3 candidates drafted
for this entry and why this one was picked.

## Run it

```sh
python3 main.py
```
